# Websites for sale

Brand mockup websites for Australian `.com.au` domains that are for sale. Each site is a single self-contained `index.html` (inline CSS and SVG logos, Google Fonts only), so it can be uploaded to any static host and pointed at its domain.

| Domain | Brand concept | Folder |
|---|---|---|
| mixr.com.au | Mixr: craft cocktail mixers with native Australian botanicals | `sites/mixr.com.au/` |
| subsave.com.au | SubSave: subscription tracker that finds and cancels forgotten charges | `sites/subsave.com.au/` |
| finz.com.au | Finz: performance surf fins for Australian waves | `sites/finz.com.au/` |
| syntropy.com.au | Syntropy: regenerative agroforestry and land design | `sites/syntropy.com.au/` |
| myweddingrings.com.au | My Wedding Rings: custom Australian-made wedding bands | `sites/myweddingrings.com.au/` |

`index.html` at the root is a portfolio page that links to every brand.

Each brand site includes a "for sale" banner, a product/service mockup, a brand kit (logo, palette, typography, tagline and voice) and an acquisition section.
